CATEGORY 1: SLAM MAPPING (Single-Loop Mapping)
================================================================================

Step 1.1: Launch Mapping Stack on Raspberry Pi
----------------------------------------------
MACHINE: Raspberry Pi
PATH   : ~/ros2_ws
COMMAND:
  export ROS_DOMAIN_ID=10
  export CYCLONEDDS_URI=file://$HOME/cyclonedds.xml
  export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
  source /opt/ros/humble/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 launch robot_mapping mapping.launch.py arduino_dev:=/dev/ttyACM0

PURPOSE: Launches Arduino bridge, RF2O laser odometry, RPLidar scan, SLAM Toolbox
         (online_async mode), and Rosbridge WebSocket server (port 9090).


Step 1.2: Drive Robot to Map the Area (Teleop)
-----------------------------------------------
MACHINE: Raspberry Pi (or Laptop over ROS domain 10)
PATH   : ~/ros2_ws
COMMAND:
  export ROS_DOMAIN_ID=10
  export CYCLONEDDS_URI=file://$HOME/cyclonedds.xml
  export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
  source /opt/ros/humble/setup.bash
  ros2 run teleop_twist_keyboard teleop_twist_keyboard

PURPOSE: Drive the robot smoothly in a single continuous loop around the room
         to generate a clean SLAM map without duplicate walls.

CATEGORY 2: SAVE MAP
================================================================================

Step 2.1: Save SLAM Map to File
-------------------------------
MACHINE: Raspberry Pi
PATH   : /home/damith-raspberry/maps
COMMAND:
  export ROS_DOMAIN_ID=10
  export CYCLONEDDS_URI=file://$HOME/cyclonedds.xml
  export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
  source /opt/ros/humble/setup.bash
  mkdir -p ~/maps
  ros2 run nav2_map_server map_saver_cli -f /home/damith-raspberry/maps/server_room

PURPOSE: Saves the generated map as /home/damith-raspberry/maps/server_room.yaml
         and /home/damith-raspberry/maps/server_room.pgm.
         *NOTE*: Always use absolute paths to prevent ImageMagick tilde bugs.

------------------------------------

PATH   : ~
COMMANDS:
